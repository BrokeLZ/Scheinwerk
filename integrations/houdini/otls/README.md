# Scheinwerk HDAs

Save the three Scheinwerk HDAs here, so the package puts them on Houdini's path:

- `sw_publish_sop.hda`
- `sw_publish_lop.hda`
- `sw_render.hda`

With Houdini Indie the extension is `.hdalc`, with Apprentice `.hdanc`.

How to build them: see "Building the HDAs" in `docs/usage.md`.
